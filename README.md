# api-interna-de-carro
As informações vem de um arquivo json com curtas informações de carros, tendo 10 carros com as seguintes infomações, nome ou modelo, marca, categoria, e 3 fotos,feito em react apenas para praticar, por isso nao liguem que a pagina pode estar não tão bonita.
